## Patterns worth copying (inferred)

- **Search first, then edit.** Every edit turn starts with qsm plus fis. `find_in_script` takes several typed queries at once: `filler-words`, `silence-gaps{minDurationSeconds}`, `pattern{pattern, flags}`, and `text{scriptText, prefix, suffix}`. Results carry `[ref:…]` handles.
- **Re-search after time-shifting edits.** After `shorten_word_gaps`, old text ranges went stale and an edit failed. The model recovered by searching again. An editor of our own should either re-anchor ranges or return the same error so the model can retry.
- **Verify with a cheap read.** B2 ends with a filler-words search that must return 0. B3 and B4 verify visual changes with `screenshot`, which costs one vision sub-call per call.
- **Reframing loops are expensive and can fail to converge.** In B4, five screenshot → edit rounds never satisfied "matches intent". Cap these loops in our agent ([../../pseudocode/underlord/agent-loop.md](../../pseudocode/underlord/agent-loop.md)).
